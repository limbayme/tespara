## 每次上传的同步要求

每次使用 Codex 上传 Excel、商品图片或其他素材时，必须在同一次更新中核对并更新根目录的 `README.md` 和 `PRICING.md`，随后一起提交到 GitHub。

1. `README.md`：更新核对日期、最新素材路径、SKU / 图片数量、本次新增或替换内容及链接，明确当前版本和历史版本。
2. `PRICING.md`：如果有新定价 Excel，按 SKU 同步全部价格、渠道和促销备注，标明源文件及价格版本日期；如果仅更新素材，保留现有价格，更新素材链接、核对日期，并注明“价格未变”。
3. 提交前检查 SKU 对应关系、价格字段和链接是否正确。缺失或冲突的价格应明确标记待确认，不自行补值；提交后提供 GitHub 文档链接和变更摘要。

文档文件名统一为 `README.md` 和 `PRICING.md`，不要另建 `READ.md`。后续上传应继续保留本节同步要求。
